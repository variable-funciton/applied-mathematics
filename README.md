# 応用数学ラボ(Streamlit)

教科書の目次(分野 → 章 → 節)に沿って、スライダーで動かして学ぶ Web アプリ。
サイドバーで分野と章を選び、画面上部で節を選ぶ。選んだ節だけを計算するので軽い。

## 動かし方

```
pip install -r requirements.txt
streamlit run app.py
```

Streamlit Community Cloud では、このフォルダを GitHub リポジトリに置き、Main file に `app.py` を指定する。

## 節を追加・修正するには

各節は `topics/*.py` の `tab_○○()` 関数1つ。各節の最後の「練習問題」は、問題を先に並べ、「解答・解説を表示」をオンにすると答えが出る。新しい関数を書いて、`app.py` の `CURRICULUM` の該当する章のリストに
`("節の名前", モジュール.関数)` を1行加える。並び順もここで変えられる。

## 演習(自習用の類題)

- ベクトル解析の第1章〜第3章の最後に「演習」がある(`ex_ch1.py`, `ex_ch2.py`, `ex_ch3.py`)。第1章には「曲線を表すベクトル関数(円・線分・直線)」、第3章は線積分(逆向きの曲線 $-C$、曲線をつないだ $C_1+C_2$ を含む)・ポテンシャル・グリーンの定理・面積分・ガウス・ストークス・楕円の反射。
- ラプラス変換の第1章・第2章の最後にも「演習」がある(`ex_laplace.py`)。第1章:公式による変換、第1・第2移動法則、像関数の微分法則、逆変換(部分分数・平方完成)。第2章:合成積、微分方程式の解法、伝達関数とインパルス応答。難易度(基本/標準)と問題の型を選び、4択で解く。
- 「セット番号」が同じなら同じ問題が出る。「同じ型でもう一問」で数値だけを変えた類題になる。
- LaTeX 一式(数学IB と同じ構成:本体 `数学IV演習.tex` / `数学IV演習-Ans.tex` と、`\input` される `problems.tex` / `answers.tex`)を zip でダウンロードできる。プリアンブルや年度・クラスの行は `topics/ex_core.py` の `PREAMBLE`・`NENDO`・`CLASS_LINE` で変えられる。
- 問題を増やすときは、`topics/ex_ch1.py` のように生成関数を書いて `REGISTRY` に登録する。誤答は典型的な間違いから作り、`why` にその誤答を選んだときの指摘を書く。

## 記述式の問題セットの作成(管理人用)

- サイドバーの「🔒 管理人用」。演習と同じ生成関数から、章をまたいで問題の型と題数を選び、記述式の問題セットを作る。
- 1題10点。「【誘導 5点×2】」の型は、同じ数値で (1)(2) の小問に分けた1題になる。
- 問題番号が同じなら同じ問題セットが再現できる。LaTeX 一式(本体2つと `problems.tex` / `answers.tex`)を zip でダウンロードする。
- 使うには管理人用パスワードの設定が必要。Streamlit Community Cloud ではアプリの Settings → Secrets に
  `admin_password = "(パスワード)"` と書く(以前の名前 `teacher_password` のままでも動く)。手元では `.streamlit/secrets.toml` に同じ1行を書く(GitHub には上げない)。
- 範囲に章を加えるときは、`topics/admin.py` の `CHAPTERS` に1行足す(表示名は「分野 第○章 …」の形で、分野をまたいでも重ならないようにする)。
- 図が必要な問題(グリーンの定理の領域など)は、`topics/ex_fig.py` の同じ仕様から、Web では plotly、LaTeX では方眼つきの TikZ を作る。

## 学生用 PDF

- 各章の演習の最後、「LaTeX 一式をダウンロード」の右に「すぐに取り組みたい学生はこちらでダウンロード」がある。
  「PDF を作る」を押すと、問題 → 解答・解説の順の PDF をサーバーで作る(uplatex + dvipdfmx)。
- Streamlit Community Cloud では、リポジトリ直下の `packages.txt` に書いた日本語 LaTeX がデプロイ時に入る
  (初回のデプロイは数分長くかかる)。
- サーバーに LaTeX がない場合は、代わりに印刷用ページ(.html、数式は KaTeX)を出す。ブラウザの「印刷」→「PDF に保存」で PDF になる。
- 図は `topics/ex_fig.py` の仕様に `"complex": True` を付けると、LaTeX ではコメントアウトして出力する(必要なら % を外す)。

## 時間発展のアニメーション(「▶ シミュレーション開始」)

- ⑤「時間発展シミュレーション(熱・波動)」(`pde_sim.py`)と、②「ばね・ダンパーの振動」(`lap_sim.py`)。
- 境界条件・初期条件を選んでボタンを押すと再生する。再生部品は `topics/player.py` の `player()` で、`st.fragment` の中で
  `st.empty()` に1コマずつ描き直す(ページ全体は再実行しない)。計算は `st.cache_data` で先に済ませ、再生中は描画だけ。
  1コマの描画時間を測って待ち時間から引くので、速さが一定になる。再生のあとは「時刻」のスライダーで好きな瞬間に戻せる。
- 熱伝導:クランク・ニコルソン法(最初の2ステップは後退オイラー法)。境界は 両端固定温度 / 両端断熱 / 左固定・右断熱 / 地表面の周期的な温度変化(地盤)。
- 波動:中心差分(クーラン数 0.9)。境界は 両端固定 / 両端自由 / 左固定・右自由(地盤・建物のせん断振動)/ 左端を正弦波で揺らす(地震の揺れの入力、共振)。減衰 γ と初速度も選べる。
- 外力のない場合はフーリエ級数の厳密解と重ねて比べられる。時空間図(x–t 図)で反射のようすが一目でわかる。
- 再生の速さ・コマ数の上限は `player.py` の `SPEEDS`・`MAX_LIVE` で変えられる。

## 例:天気予報の風(`wind.py`)

- 風向(吹いてくる方向、北から時計回りの角 θ)と風速 V から、$u=-V\sin\theta$(東向き)、$v=-V\cos\theta$(北向き)を作る。
- モデルの渦(ランキン渦 + 吹き込み角):回転・発散の値と、閉曲線に沿う循環・流出量(グリーンの定理で一致することを確かめる)。
- 実際の予報データ:Open-Meteo(APIキー不要、データは CC BY 4.0)から地上 10 m の風を格子状に取得し、差分で rot・div を求めて地図に描く。
  「予報データを取得して表示する」をオンにしたときだけ通信し、結果は1時間キャッシュする。取得できないときは注意を表示する。
